# Synergy IME Guard v0.1.0

First public release of the native macOS guard for Synergy punctuation loss
when a Mac server uses Simplified Chinese Pinyin.

## Highlights

- Native Swift executable with no third-party runtime or package dependency.
- Universal macOS binary for Apple Silicon and Intel.
- Server-role and language-sync gates; passive behavior on Synergy clients.
- Durable input-source restoration across duplicate events, restarts, log
  rotation, server loss, upgrade, and uninstall.
- Per-user installer with no root or Accessibility permission.
- English and Simplified Chinese documentation.

## Tested scope

- Synergy 3.6.3
- macOS 26.5.1 and 26.5.2 on Apple Silicon
- Simplified Chinese Pinyin and ABC
- Active Mac server and passive Mac client
- Fresh install, idempotent upgrade, pending-state upgrade, injected activation
  failure rollback, and uninstall restoration logic

Windows and Linux remote clients are inside the architecture boundary but were
not physically tested for this release. Deskflow is not yet claimed as
supported.

## Verification

Download the archive and its `.sha256` file, then run:

```bash
shasum -a 256 -c synergy-ime-guard-v0.1.0-macos-universal.tar.gz.sha256
```

The executable is ad-hoc signed and is not Apple-notarized.
